# Terminator Gruvbox + Solarized

This built-in scheme reproduces the local Terminator setup: Gruvbox Dark for
the terminal background and normal text, Solarized Dark for the 16 terminal
colors, and Mint-Y-Dark-Aqua colors for the application interface.

```lua
config.color_scheme = 'Terminator Gruvbox + Solarized'
```

The setting also colors the tab bar, title bar, command palette, pane and
character selectors, split lines, scrollbar, selection, cursor, and compact
right-click menu.
