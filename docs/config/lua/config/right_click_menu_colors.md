# `right_click_menu_colors`

Controls the colors of the compact right-click menu.

```lua
config.right_click_menu_colors = {
  background = '#2e2e33',
  border = '#141416',
  button_background = '#2e2e33',
  foreground = '#dadada',
  disabled_foreground = '#87878a',
  hover_background = '#46464e',
  focus_border = '#525257',
}
```

The built-in `Terminator Gruvbox + Solarized` color scheme sets these and the
other application colors together.
